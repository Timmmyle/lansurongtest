# Liên đoàn Lân Sư Rồng Việt Nam · Website redesign

Trang so sánh hai phiên bản thiết kế trang chủ.

| Đường dẫn | Nội dung |
|---|---|
| `/` | Trang chọn phiên bản: hiển thị toàn màn hình, thanh nút V1 / V2 ở dưới |
| `/#v1`, `/#v2` | Mở thẳng một phiên bản (gửi link cho người duyệt) |
| `/v1/` | Bản cũ: editorial, Playfair Display (1 file HTML) |
| `/v2/` | Bản mới: bố cục thẻ theo wireframe, logo + font + bảng màu LĐLSRVN |

Site tĩnh, không cần build. Deploy trên Vercel với Framework Preset = **Other**.

Thay ảnh gốc độ phân giải cao: chép đè vào `v2/assets/img/` (giữ nguyên tên file).
Font chính thức: đặt `LDLSR.woff2` vào `v2/assets/fonts/`.
